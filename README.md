# 貝柱を綺麗に取るゲーム

スマートフォン横画面向けの Three.js / Rapier プロトタイプです。

## 起動・確認

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

右側をスワイプしてヘラを移動し、左下のダイヤルで回転します。PCはドラッグと A / D または左右矢印に対応します。開始時の指の位置には瞬間移動せず、二本のポインターを独立管理します。タブが非表示の間はタイマーを止めます。

`dist/` を静的ホストへ配置できます。Viteの `base: './'` により GitHub Pages のリポジトリ配下に対応しています。公開自体は未実施です。

## 現在のルール

- 弱い力では未剥離の貝柱に押し返され、中程度の力で剥離、強すぎる力で直接当たった直方体の結合を切ります。
- **点数は、剥離済みの最大の結合集団に含まれる直方体の数そのものです。** 合計剥離数や百分率ではありません。
- 結合は上下左右の隣接グラフで保持し、一度切った結合は衝突しても復活しません。
- 未剥離の直方体を経由するつながりは現在の点数には含めませんが、今後の得点上限には含めます。
- 全て剥離、制限時間終了、またはどの集団を完成させても現在の最大点を上回れなくなった時点で結果画面へ移行します。
- 現在小さい別の集団でも、その集団を剥がし進めて点数を更新できるなら続行します。同点までしか届かない場合は終了します。
- 千切れた直方体も剥離済みの独立した1本の集団です。最大集団を超えない限り加点されません。従来の「破損分を全て除外する百分率方式」は廃止しています。
- 終了時に点数と操作を確定・停止し、浮き上がり演出から3Dの盛り付け結果画面へ切り替えます。

## 表示と内部構造

- `src/rules.js`: 調整値、結合グラフ、切断、最大集団の採点と終了判定。
- `src/models.js`: 殻、格子状の直方体データ、滑らかな外皮。
- `src/physics.js`: Rapierの3D衝突、集団の剛体化、ヘラ操作の接触処理。
- `src/main.js`: 画面、入力、120 Hz固定更新、実時間タイマー、結果・リトライ。

内部は同じ高さの直方体です。未剥離の表示は、提供画像を参考にした平らな上面・垂直に近い側面・前側の小さなくびれを持つ楕円柱です。初期状態は連続した一枚の外皮で、格子線はありません。殻から剥離しただけでは外皮の形と結合を維持し、剥離した部分の色だけ変更します。完全剥離して飛んでも楕円柱の形を保ちます。結合が切れて千切れた直方体だけBoxGeometryによる箱形に切り替え、そのときに残る集団の外皮を再生成します。

殻は、直線に近い背縁、湾曲した腹縁、細い殻頂、薄い断面を持つ非対称の三角形です。下記の形態資料とユーザー提供の写真を参照した手続き生成モデルです。写真から精密に復元したモデルではありません。

- うおいち「旬の魚 タイラギ」 https://www.uoichi.co.jp/assets/attachmentfile/attachmentfile-file-668.pdf

貝柱に隠れたヘラの刃・柄は、隠れた範囲だけ濃い青緑の点線輪郭を表示します。深度とステンシルで判定するため、露出部分や殻だけに隠れた部分には点線を出しません。輪郭はヘラの移動・回転に追従します。

床も3Dの平面です。カメラは上方から少し傾けて、上下への飛散と殻の反りを見やすくしています。

## 物理の構成と制約

- ヘラの刃・柄：それぞれ直方体の衝突形状。ヘラは操作に追従するキネマティック物体。
- 貝柱：結合集団ごとに直方体コライダーをまとめた複合剛体。集団内は自己衝突せず、結合を維持します。
- 未剥離が残る集団：殻に拘束され、全体のバネ揺れと滑らかな浮き上がりを表現。
- 完全剥離した集団・千切れた破片：動的剛体。初速度と角速度を与え、重力・減衰・接触によって飛翔、回転、落下、反発します。一定高度へ引き戻す旧方式は廃止しました。
- ヘラと貝柱は、実際の高さ・角度を含めて接触判定します。刃が浮いた部分の下を通るだけでは破損しません。
- 剥離済み部分への柄の接触では移動を一律停止しません。未剥離部分との平面上の重なりが増える動きだけを止め、重なりを減らす引き抜きや、重なりを増やさない横滑りは許可します。弱い刃の接触にも同じ脱出判定を使います。柄が原因で止まった場合は専用メッセージを表示します。
- 独立した集団同士、および貝柱とヘラ・殻の曲面・床はRapierで接触します。殻とヘラの刃・柄の組み合わせは衝突フィルターから除外し、手動の接触・押し返し・殻を押す処理も削除しています。ヘラは一定の操作高さで殻の縁を通過できます。
- 殻は厚みを持つ三角形メッシュの固定コライダーです。貝柱や破片は衝突しますが、ヘラでは殻を動かしません。
- 接着中の集団と殻は拘束関係を優先して反発させません。離れた集団は殻との衝突を有効にします。
- 飛散速度には上限を設けています。

## 調整と検証

「調整」で力の閾値、感度、飛散・回転速度などを変更できます。本数・幅・制限時間は再スタートで反映します。直方体の幅は指定値を上限とし、大きすぎる場合は殻に収まるよう縮小します。設定は保存しません。

自動テストには、提示された終了例、別集団による逆転可能性、結合切断、剥離後の自由回転、各種3D接触、殻とヘラの衝突除外・剥離時の形状維持・千切れた部分だけの直方体表示、リセットを含めます。

スマートフォン実機での二本指操作とフレームレートは別途確認が必要です。RapierのWASMを同梱するため初回ダウンロードは従来より大きくなります。大きな集団が分裂した際は外皮の再生成が発生します。

## 結果の盛り付け演出

終了した瞬間に点数と経過時間（小数1桁）を確定します。貝柱が浮き上がり、明るい切り替え演出の後、独立した3Dの盛り付け画面へ移ります。最大の剥離済み集団を刺身皿へ盛り付け、立体の大根のつま、醤油入りの小皿、箸を添えています。0点の場合は貝柱を盛り付けません。

紙吹雪と短いファンファーレで結果を祝います。右上の「音」ボタンで消音できます。演出時間は所要時間に含めず、リトライで演出・物理・採点を初期化します。

ヘラの操作高さは殻の実メッシュと刃・柄の占有範囲から計算します。殻の縁では自動で持ち上げ、内側では通常の差し込み高さへ戻します。殻との横方向の衝突・押し返しは引き続き無効です。

## 琴のBGM

プレイ開始後、琴のサンプルを使ったオリジナルの16小節（84 BPM、約46秒）がループします。音量は効果音より控えめにしています。結果画面・消音・別タブへの切り替えで止まり、リトライでは先頭から再生します。「音：ON／OFF」はBGMと効果音の共通スイッチです。

音源：FluidR3_GM（Frank Wen）、MIDI.js Soundfonts（Benjamin Gleitzman）によるレンダリング。配布元表記のCC BY 3.0 USに従い、出典と利用条件を `public/audio/koto/CREDITS.txt` に収録しています。曲はこのゲーム用に作成したものです。必要な9音（計約164 KB）のみ同梱し、プレイ中に外部サイトへのアクセスは行いません。

## GitHub Pagesでの公開

1. GitHubのリポジトリで Settings → Pages → Build and deployment → Source を GitHub Actions に設定。
2. `.github/workflows/deploy.yml` をコミットして main にpush。
3. Actionsの「Deploy game to GitHub Pages」が成功すると https://Ragulai1214.github.io/kaibasira/ で公開。

以降はmainへのpushごとにテスト・ビルド・公開が自動で実行されます。公開URLで遊ぶ際にローカルPCの起動や `npm run dev` は不要です。`dist` をGitへ追加する必要もありません。公開用ビルドは `--base=/kaibasira/` を指定し、琴の音源も含めて配信します。
